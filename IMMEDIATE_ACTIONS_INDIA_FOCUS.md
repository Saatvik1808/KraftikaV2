## ⚡ Quick Start: Do These This Week

### Day 1-2: Google Analytics Setup

**✅ Action Items:**

1. **Create India-Only View in Google Analytics**
   - Go to your GA4 dashboard
   - Create a comparison segment for "India Users"
   - See detailed steps in `GOOGLE_ANALYTICS_INDIA_SETUP.md`

2. **Update Geographic Settings**
   - Admin → Property Settings
   - Set Timezone: India Standard Time (GMT+05:30)
   - Set Currency: Indian Rupee (INR)

**Time Required:** 30 minutes

### Day 2-3: Google Search Console

**✅ Action Items:**

1. **Verify Your Website**
   - Go to https://search.google.com/search-console
   - Add property: Your website URL
   - Verify using HTML tag (already in your code) or DNS

2. **Submit Sitemap**
   - After verification, go to Sitemaps
   - Submit: `https://yourdomain.com/sitemap.xml`

3. **Set Geographic Target**
   - Settings → International Targeting
   - Target: India (IN)

**Time Required:** 1 hour
