## 📊 Part 1: Google Analytics - Focus on India

### Step 1: Create India-Only View in Google Analytics

**Action Required in Google Analytics Dashboard:**

1. **Go to Admin → Views → Create View**
   - View Name: "India Traffic Only"
   - Reporting Time Zone: (GMT+05:30) India Standard Time
   - Currency: Indian Rupee (₹)

2. **Add Filter for India Traffic**
   - Go to Admin → Filters → Create Filter
   - Filter Name: "India Traffic Only"
   - Filter Type: Predefined
   - Select: Include only → Traffic from the countries → that are equal to → India
   - Apply this filter to "India Traffic Only" view

3. **Create Additional Segments**
   - Go to Reports → Add Comparison
   - Create custom segment:
     - Name: "India Users"
     - Conditions: Country = India
   - Save this segment for quick access

### Step 2: Set India as Default Geographic Focus

**In Google Analytics 4:**
1. Go to Admin → Property Settings
2. Set Default Reporting Time Zone to (GMT+05:30) India
3. Set Default Currency to Indian Rupee (INR)
4. Enable "Geographic Targeting" if available

### Step 3: Enhanced Tracking Configuration

**Already implemented in your code** - but verify these settings in GA4:
- Check if country data is being collected properly
- Set up custom reports for Indian cities (Mumbai, Delhi, Bangalore, etc.)
- Enable enhanced measurement for better data collection
